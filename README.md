# ONLYOFFICE Help Center scripts

Scripts referenced in [ONLYOFFICE Help Center](https://helpcenter.onlyoffice.com) articles.
Each folder corresponds to one article: `<product>/<article-name>/`.

## Scripts

| File | Article | Product |
|------|---------|---------|
| [kylin-seccomp7.json](docs/docs-community-install-docker-kylinos/kylin-seccomp7.json) | [Installing ONLYOFFICE Docs on KylinOS using Docker](https://helpcenter.onlyoffice.com/docs/installation/docs-community-install-docker-kylinos.aspx) | ONLYOFFICE Docs |
| [install.sh](workspace/control-panel-sso-shibboleth/install.sh) | [Configuring Shibboleth IdP for SSO](https://helpcenter.onlyoffice.com/workspace/administration/control-panel-sso-shibboleth.aspx#creatingshibbolethidp_block) | ONLYOFFICE Workspace |

## Usage

Follow the instructions in the corresponding article. To download a script directly:

```bash
curl -L -o install.sh https://raw.githubusercontent.com/ONLYOFFICE/helpcenter-scripts/master/workspace/control-panel-sso-shibboleth/install.sh
```

Review a script before running it. The scripts are examples provided as is
and may need changes for your environment.
