# ONLYOFFICE Help Center scripts

Scripts referenced in [ONLYOFFICE Help Center](https://helpcenter.onlyoffice.com) articles.
Each folder corresponds to one article: `<product>/<article-name>/`.

## Usage

Follow the instructions in the corresponding article.

Review a script before running it. The scripts are examples provided as is
and may need changes for your environment.

## Feedback

Found a problem with a script? [Open an issue](https://github.com/ONLYOFFICE/helpcenter-scripts/issues).
